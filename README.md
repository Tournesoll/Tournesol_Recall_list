# Recall Lite

Recall Lite 是一个为考研背诵场景设计的轻量级记忆工具。我在备考过程中希望有一个更贴合自己的背诵流程，于是做了这个项目：把知识库整理、间隔复习、遗忘曲线和多种卡片形式放在一个简单的本地应用里。

项目目前提供 Web 版和 Android WebView 壳。数据默认保存在当前浏览器的 IndexedDB 中，不依赖后端账号，也不会自动把个人背诵内容上传到服务器。

## 主要功能

- 知识库管理：创建、重命名、删除和迁移知识库。
- 分类管理：支持顶级分类、子分类和多级分类树。
- 多种内容形式：回忆卡、填空卡、选择题。
- 快速添加：手动添加、按格式批量粘贴、AI 整理后导入。
- 添加页内建库：添加内容时可以直接创建知识库并选择所属分类。
- 精细选词：按分类、知识库、内容形式和复习范围选择本轮内容。
- 背诵队列：认识、模糊、忘记会影响队列顺序；困难内容会稍后再次出现。
- 中途退出恢复：退出背诵时自动保存进度，下次进入时可以选择继续。
- 长期遗忘曲线：复习间隔最长延伸到多年，每条内容维护自己的复习系数。
- 学习记录：查看复习热力图、掌握情况、未来复习压力，以及每天按知识库统计的新增内容。
- 本地备份：可在设置页导出和导入 JSON 数据。

## 快速开始

### Web 版

环境要求：Node.js 18 或更高版本。

```bash
npm install
npm run dev
```

然后打开终端显示的本地地址，通常是 `http://localhost:5173/`。生产构建：

```bash
npm run build
npm run preview
```

### 第一次使用

1. 打开“知识库”，先创建一个顶级分类，例如“英语”。
2. 在分类下创建子分类，例如“词汇”“长难句”。
3. 创建知识库，例如“考研核心词”。
4. 点击“添加内容”，选择知识库和卡片形式，再保存内容。
5. 打开“背诵”，按分类或知识库选择本轮范围。
6. 每张卡片完成后选择“认识”“模糊”或“忘记”，系统会更新队列和下次复习时间。

### 添加格式

在“按格式粘贴”页面可以批量导入。推荐使用 JSON：

```json
{
  "version": 1,
  "items": [
    {"type": "recall", "question": "abandon", "answer": "放弃；抛弃"},
    {"type": "cloze", "content": "新中国成立于{{1949年}}。"},
    {"type": "choice", "question": "下列哪项属于记忆卡？", "options": ["问题和答案", "只有图片"], "correctIndex": 0}
  ]
}
```

填空卡用 `{{答案}}` 标记需要遮挡的部分。选择题的 `correctIndex` 从 `0` 开始。AI 整理页面支持选择输出形式，生成后请先检查内容再导入。

## 背诵规则

每条内容都有独立的复习等级、下次复习时间和复习系数。

- 认识：记录本次复习，并延长复习间隔。
- 模糊：保留在当前队列稍后再次出现，适当延长间隔。
- 忘记：重新强化，降低复习等级并尽快再次出现。

如果在背诵途中退出，页面会保留当前队列、已完成内容和卡片状态。重新进入背诵时可以继续上次进度，也可以开始新一轮。

## Android 版

Android 工程位于 [`android/`](android/)。它使用原生 WebView 加载 Web 构建资源，适合在 Android Studio 中继续开发或打包。

构建前需要安装 Android Studio，并确保 Gradle、Android SDK 和 JDK 可用：

```powershell
powershell -ExecutionPolicy Bypass -File .\android\sync-web.ps1
cd android
.\gradlew.bat assembleDebug --offline
```

Debug APK 输出在：

`android/app/build/outputs/apk/debug/app-debug.apk`

也可以直接用 Android Studio 打开 `android/` 工程后运行或构建。

## 数据与隐私

Recall Lite 默认是本地优先应用：知识库、内容、复习记录和设置保存在浏览器本地。清除浏览器站点数据会删除当前设备上的数据，因此建议定期在“设置”中导出 JSON 备份。导入备份前请确认文件来源，公开仓库中不要提交个人背诵数据或 API 密钥。

## 开发说明

- 本地数据：Dexie / IndexedDB。
- 数据校验：Zod。
