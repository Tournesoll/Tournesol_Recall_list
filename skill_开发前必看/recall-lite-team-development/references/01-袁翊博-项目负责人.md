# 袁翊博开发与集成规范

## 1. 职责定位

你负责基线冻结、缺陷修复、跨模块接入、最终代码评审、GitHub 合并、数据迁移复核和 Android APK 交付。并行开发阶段不要与贾源同时修改 `src/App.tsx`、`src/db.ts`、`src/styles.css`、`src/v2.css`；将完善和修补集中到两个功能分支合并之后。

## 2. 页面整体责任

最终需要确认所有当前页面可用，并完成以下接线：

- `/settings`：接入 MiMo API Key 配置组件，确认密钥只存本地且备份不包含密钥。
- `/add/ai`：接入应用内 MiMo 生成、预览和导入，同时保留外部 AI 提示词流程。
- `/study/tasks`：接入任务列表路由和任务恢复入口。
- `/study/setup`：从“立即开始一次性队列”调整为创建/更新持久化任务。
- `/study`：接入暂停任务、详细介绍和临时问 AI。
- `/records`：接入 7/30 天 AI 学习分析。
- 所有页面：检查底部导航、返回行为、空状态、错误状态和移动端长文本。

## 3. 允许修改的文件

阶段 0 和集成阶段允许修改：

- `package.json`、`package-lock.json`
- `src/main.tsx`
- `src/App.tsx`（只在贾源分支停止修改并准备合并后）
- `src/db.ts`、`src/schemas.ts`
- `src/styles.css`、`src/v2.css`（集成修复阶段）
- `src/features/**` 中仅用于接线、修复集成错误的文件；不得重写成员已完成模块而不说明原因
- `android/**`、`vite.config.*`
- `开发后产出文档/袁翊博/合并与发布说明.md`

不要修改杨桀浩负责的 `开发报告.md` 正文；发现事实错误时通过 Issue 或评审意见反馈。

## 4. 集成步骤

1. 冻结基线：保存当前未提交变更，运行构建，记录 commit 和现状。
2. 审查贾源 PR：重点检查 IndexedDB 升级、多任务恢复、旧数据兼容、长文本和移动端。
3. 合并贾源 PR。
4. 审查候舒扬 PR：确认其只新增 `src/features/ai/**`，没有密钥和共享文件改动。
5. 合并候舒扬 PR。
6. 在共享页面接入 AI 组件、任务组件和数据库适配。
7. 统一 `explanationType` 兼容策略：旧数据可读，新数据统一写“题目解析”。
8. 统一 Markdown 渲染和安全策略，不同时保留多套渲染器。
9. 执行全量 Web 回归，再同步 Android 资源并构建 APK。

## 5. 重点缺陷检查

- 未配置 API Key 时，不得发送请求；提供去设置页的明确入口。
- API Key 不进入 V2 备份、TXT 导出或控制台日志。
- 浏览器直接请求若遇到 CORS，必须如实记录；不得假装请求成功。Android WebView 也要单独验证。
- AI 导入预览编辑后的内容必须再次校验再入库。
- 自动修复严格限制 3 次，取消后不得继续后台重试。
- 切换背诵卡片后清空 AI 答疑状态。
- 任务数量限制只计算未完成任务；完成历史不得阻止新建。
- 旧的单任务 `localStorage` 快照需要明确迁移或安全忽略，不能与新任务产生双重恢复弹窗。
- 删除条目/知识库后，旧任务中的失效 id 不得造成空白页或死循环。
- Android 返回键、系统分享、文件选择和软键盘布局需要真机检查。

## 6. 测试规范

- `npm run build`。
- 全部路由逐页打开，未知路由回退行为正常。
- 新安装空数据库、从当前 V5 数据库升级、新建任务后刷新、暂停后杀进程再恢复。
- 三个未完成任务达到上限，完成一个后可继续新建。
- AI 三类功能分别验证成功和失败；至少覆盖未配置 Key、错误 Key、超时、429、非法 JSON、第三次修复失败。
- 在 360×800 和一台实际 Android 设备检查横向溢出、弹窗、输入法和底部操作栏。
- 运行 `android/sync-web.ps1` 后确认 assets 与最新构建一致，再构建 Debug APK。

测试完成后删除临时数据、模拟响应、测试路由、调试日志、截图脚本和真实 Key。不要删除团队约定保留的正式测试。

## 7. 合并后输出

填写 `开发后产出文档/袁翊博/合并与发布说明.md`，至少记录：

- 最终合并顺序和 commit/PR。
- 每个共享文件为什么修改。
- 数据库版本及迁移策略。
- MiMo 配置和直接请求的实际验证结果。
- Web、Android 构建命令和结果。
- APK 路径、版本信息和真机型号。
- 已解决冲突、未解决问题和下一步建议。
