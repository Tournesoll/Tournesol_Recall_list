# 候舒扬 AI 开发规范

## 1. 任务范围

负责统一 MiMo v2.5 能力层及三个 AI 场景：

1. AI 导入背诵卡片。
2. 背诵答案揭晓后的临时问 AI。
3. 记录页最近 7/30 天学习分析。

不负责页面总路由、IndexedDB 多任务、全局 UI 改版或 Android 打包。不得把真实 API Key 放入代码。

## 2. 页面整体概述

### `/settings`

提供可嵌入的 MiMo 配置组件：填写、更新、清除和遮挡显示 API Key；显示是否已配置。配置只存本机，不进入数据库备份。

### `/add/ai`

提供可嵌入的 AI 生成流程：输入来源、卡片类型、题目解析开关、发送、自动修复、结果预览。现有外部 AI 提示词模式由负责人保留和接线。

### `/study`

提供可嵌入的 `StudyAiQuestionPanel`。只有父页面传入 `revealed=true` 时可打开；卡片 id 变化时必须清空全部局部状态。

### `/records`

提供可嵌入的学习分析组件。父页面只传聚合数据；组件支持 7/30 天选择、生成、重新生成和 Markdown 结果展示，但不持久化。

## 3. 允许修改的文件

只允许新增或修改：


如果需要依赖、路由、数据库或全局样式改动，在开发后说明的“需要负责人接入”中列出，不得自行修改。

## 5. MiMo 客户端要求

- 从本机配置读取 API Key，源代码中只能出现占位符。
- endpoint、model 名称、超时集中配置；依据官方接口确认请求结构，禁止猜测字段后静默吞错。
- 对上层暴露结构化错误类型，至少区分：未配置、鉴权、限流、超时、网络、服务端、取消、响应格式错误。
- 使用 `AbortController`，组件卸载和用户取消时停止请求。
- 不记录 Authorization 头、完整请求体、原始图片或私有学习资料。
- 同一操作期间禁止重复提交。

## 6. AI 导入实现要求

输入来源：

- 直接粘贴文本。
- `.txt` 文件，验证扩展名、MIME、大小和文本读取错误。
- 图片，验证格式、数量和大小；转换为 MiMo 接口需要的多模态输入。预览 URL 用完释放。

提交前收集：

- 允许的卡片类型，可多选但至少一项。
- 是否生成题目解析。
- 用户原始资料。

输出仍为 `version: 1` 和 `items`。新数据若有解析，使用 `explanation`，可兼容写 `explanationType: "题目解析"`；不要再生成单词解释等分类。

自动修复：

1. 首次输出本地解析并校验。
2. 失败时将精简错误列表和原始输出提交给修复提示词。
3. 最多发起 3 次修复请求，计数在 UI 可见。
4. 用户取消、鉴权失败或明显不可重试错误立即停止。
5. 最终失败时保留可复制的原始输出和错误摘要，不自动写数据库。

预览：

- 展示类型、题面、答案/遮挡/选项、正确项和解析。
- 支持逐条编辑、删除。
- 输出给负责人的是再次校验过的结构化 items，通过 `onConfirm(items)` 回调交接；AI 模块不直接写 Dexie。

## 7. 背诵答疑实现要求

- Props 至少包含 `itemId`、类型、题面、答案、选项/正确答案、解析、`revealed`。
- `revealed=false` 不显示或不允许发送。
- 提示词只携带当前卡片必要上下文，并明确拒绝无关问题。
- 默认单轮：一个输入框、发送、取消、错误、回答、重新提问。
- `itemId` 改变时清空输入、回答、错误和正在进行的请求。
- 不调用 IndexedDB，不写 `localStorage`，不提供“生成笔记”。
- Markdown 渲染必须安全；链接和长代码不得撑破手机页面。

## 8. 学习分析实现要求

- Props 接收负责人整理的聚合数据，例如每天复习量、认识/模糊/忘记、强化次数、知识库维度汇总和未来到期量。
- 不接收完整题目正文，不读取数据库。
- 用户可选 7 天或 30 天，默认 7 天。
- 提示词要求输出学习量、掌握趋势、薄弱方向、复习压力和可执行建议，并明确数据不足时不得编造。
- 结果仅保存在组件 state；离开页面后清空。

## 9. 对负责人提供的接口说明

开发完成后，在说明文档中给出每个导出组件的准确 import、props、回调、错误类型和 CSS 引入方式。示例只表达形式：

```ts
<AiImportWorkspace onConfirm={handleValidatedItems} />
<StudyAiQuestionPanel item={currentItem} revealed={revealed} />
<StudyAnalysisPanel summary={summary} />
<AiKeySettings />
```

不要要求负责人复制组件内部代码到 `App.tsx`。

## 10. 测试规范

- `npm run build`，不得靠跳过 TypeScript 完成。
- 使用脱敏数据验证文本、TXT、单图/多图、三种卡片组合、有/无解析。
- 验证空输入、错误文件、超限图片、取消请求、错误 Key、429、超时、5xx。
- 构造非法 JSON，验证修复成功以及连续 3 次失败后停止。
- 预览编辑后再次校验；删除全部卡片时禁止确认。
- 答疑必须验证切换 `itemId` 清空状态和中止旧请求。
- 学习分析验证 7/30 天、空数据和页面卸载后无保存。
- 在 360 px 宽度检查 Markdown、长 URL、代码块、长公式和错误文案。

测试结束后删除临时 mock、调试入口、真实响应、上传样例、API Key、控制台日志和测试页面。
