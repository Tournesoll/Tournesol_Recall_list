# 开发后产出文档索引

本目录保存每位成员完成任务后的事实性说明，是袁翊博合并和杨桀浩编写最终报告的主要输入。

## 填写位置

- 袁翊博：`开发后产出文档/袁翊博/合并与发布说明.md`
- 候舒扬：`开发后产出文档/候舒扬/开发后说明.md`
- 贾源：`开发后产出文档/贾源/开发后说明.md`
- 杨桀浩：`开发后产出文档/杨桀浩/文档工作说明.md`

## 使用规则

- 开始开发前保留模板；提交 PR 前替换所有“待填写”。
- 只记录实际完成和实际验证的内容，不把计划当结果。
- 每个修改文件都要逐项说明，不允许只给目录级概括。
- 命令写完整，结果注明成功、失败或未执行。
- 不写 API Key、Authorization 头、私人学习内容或未脱敏 AI 返回。
- 临时测试文件在提交前删除，但在文档中保留测试场景和结果。
- 未完成、降级和已知问题必须如实列出，便于合并和最终报告判断。
