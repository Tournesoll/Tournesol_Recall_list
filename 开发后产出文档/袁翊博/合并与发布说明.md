## 2.1 袁翊博当前已完成的基线工作

以下内容属于升级前项目已存在、由袁翊博负责维护并纳入本次基线的完整能力范围；不是本轮三人并行开发的新增功能：

- 搭建并维护 React 18 + TypeScript + Vite Web 应用入口，使用 `HashRouter` 和统一页面布局。
- 实现首页：今日摘要、待复习数量、打卡状态、复习量图表、记忆保持曲线、最近知识库和最近添加。
- 实现知识库管理：知识库创建、重命名、删除、分类树、子分类、移动分类、未分类管理和详情页。
- 实现三种卡片：回忆卡、遮挡填空卡、选择题，以及手动新增、编辑、删除和图片 Data URL 保存。
- 实现格式 JSON 粘贴导入、外部 AI 提示词复制、导入前校验和批次标记。
- 实现 IndexedDB 数据层：分类、知识库、背诵内容、复习日志和每日打卡，并维护 Dexie 版本迁移。
- 实现固定长期复习间隔、忘记/模糊/认识评价、强化复习、复习次数、没背会次数和保持度估算。
- 实现背诵设置：知识库/分类选择、内容类型筛选、应复习/全部/今日新增/手动选择/错题本范围。
- 实现背诵执行页：揭晓答案、选择题判定、评价、收藏、上一个撤销、进度和中途恢复快照。
- 实现复习完成页和今日打卡。
- 实现记录页：概览、30 天热力图、14 天掌握情况、记忆保持、未来复习压力、最近新增和日历明细。
- 实现错题本：收藏内容按知识库分组、编辑和取消收藏。
- 实现设置页：TXT 导出/预览/复制/下载/分享、V2/V1 备份恢复、笔记展示偏好和清空全部数据。
- 实现 Android 原生 Java WebView 壳、Web 构建资源同步脚本、Android 返回键和 Debug 构建流程。
- 完成本次基线预处理：抽取共享领域类型与 AI 接口合同、统一“题目解析”语义、清理不可达旧版路由入口、整理协作规范和交付模板。

以上基线能力的代码事实以 `项目初始情况/情况说明.md`、`项目初始情况/页面说明.md` 和基线 commit 为准。
