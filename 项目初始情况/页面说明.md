# 页面说明

以下以当前 `App` 实际启用的 V2 路由为准。应用使用 `HashRouter`，浏览器中完整地址通常为 `/#/路由`。所有主要页面都包在统一 `Layout` 中，底部固定导航包含“首页、知识库、记录、错题本”。

## 页面总览

| 路由 | 页面 | 主要用途 |
| --- | --- | --- |
| `/` | 首页 | 今日摘要、快捷操作、统计概览和最近内容 |
| `/libraries` | 知识库 | 分类树、知识库管理和入口操作 |
| `/libraries/:id` | 知识库详情 | 查看某知识库内容、状态和操作 |
| `/add` | 添加内容 | 选择手动添加、格式粘贴或 AI 导入 |
| `/add/manual` | 手动添加/编辑 | 新建或编辑一条背诵内容 |
| `/add/format` | 格式粘贴导入 | 粘贴并校验标准 JSON 后批量导入 |
| `/add/ai` | AI 整理导入 | 生成提示词、校验 AI JSON 并导入 |
| `/study/setup` | 开始背诵 | 选择知识库、内容类型、范围和具体条目 |
| `/study` | 背诵中 | 展示卡片、评价、强化、收藏和恢复进度 |
| `/study/complete` | 本轮完成 | 查看本轮统计、打卡或继续背诵 |
| `/records` | 记录 | 概览统计、日历和按知识库筛选 |
| `/mistakes` | 错题本 | 查看收藏内容并编辑/移除收藏 |
| `/settings` | 设置 | 备份、恢复、TXT 导出、显示偏好和清空数据 |

## 1. 首页 `/`

首页是默认入口，展示当前日期和“今天想背什么？”。

- 今日摘要：已复习条数、待复习条数、是否已打卡。
- “开始背诵”进入 `/study/setup`。
- “添加内容”进入 `/add`。
- 最近 7 天：按天显示复习记录数量。
- 记忆保持：显示当前预计保持度和未来时间跨度的估算曲线。
- 最近知识库：按更新时间显示最多 4 个知识库，点击进入详情。
- 最近添加：按创建时间显示最多 3 条内容，点击“查看全部”进入记录页。
- 右上角设置按钮进入 `/settings`。

## 2. 知识库 `/libraries`

知识库页以分类树展示全部知识库。

- 新建分类：创建顶级分类或在某分类下创建子分类。
- 新建知识库：可选择所属分类，也可创建为未分类。
- 添加内容：进入 `/add`。
- 分类节点显示该分类下的知识库数，支持展开/收起子分类。
- 分类支持重命名和删除；删除分类及其子分类时，关联知识库移动到“未分类”。
- 每个知识库行显示内容总数和待复习数，点击进入详情。
- 每个知识库支持删除和移动分类；删除会连带删除内容及复习记录。

## 3. 知识库详情 `/libraries/:id`

展示单个知识库的上下文和内容管理。

- 顶部显示知识库名称及所属分类。
- 状态统计：总条数、待复习条数、预计掌握度。
- 开始背诵：带 `library` 查询参数进入设置页，并默认选中该库。
- 更多操作：导出 TXT、系统分享、在浏览器打开 TXT。
- 查看详情：展开复习记录入口和全部内容入口；复习记录通过 `/records?library=:id` 打开。
- 添加内容：进入 `/add?library=:id`，后续添加页面默认使用该知识库。
- 最近复习：按最近复习时间显示最多 3 条。
- 全部内容：显示内容类型和题面摘要，可编辑或删除。

## 4. 添加内容 `/add`

添加方式选择页，提供三条入口：

- 手动添加：进入 `/add/manual`。
- 格式粘贴：进入 `/add/format`。
- AI 整理导入：进入 `/add/ai`。

从知识库详情携带 `?library=:id` 进入时，三条入口会继续保留该知识库参数。

## 5. 手动添加/编辑 `/add/manual`

用于创建或编辑一条内容。带 `?edit=:itemId` 时为编辑模式，带 `?library=:id` 时预选知识库。

- 选择知识库：支持按分类/子分类查看，并可在当前页弹窗新建知识库。
- 选择卡片形式：回忆、填空、单选。
- 回忆：填写问题和答案。
- 填空：填写含 `{{答案}}` 的上下文，可写多个遮挡。
- 单选：填写题目、2～6 个选项并指定正确选项。
- 公共字段：图片、笔记、笔记展示方式、题目解析和解析文本；旧解释类型字段仅为兼容。
- 保存新内容：生成 id、batchId、创建时间、初始复习状态并返回知识库详情。
- 保存编辑：只更新该内容的字段和更新时间。

## 6. 格式粘贴导入 `/add/format`

用于导入已准备好的标准 JSON。

- 可查看格式示例。
- 粘贴文本后点击“检查格式”，先进行 JSON 解析和 `aiImportSchema` 校验。
- 校验成功显示总条数。
- 选择目标知识库后点击导入；所有条目共用一个 `batchId`，并立即进入待复习状态。
- 导入成功返回目标知识库详情；格式错误只在当前页显示错误信息。

## 7. AI 整理导入 `/add/ai`

用于与外部 AI 配合批量整理资料。

- 选择本次允许的卡片类型：回忆、填空、选择题，至少保留一种。
- 可选择让外部 AI 生成题目解析。
- 页面根据选择动态生成完整提示词，支持复制。
- 用户在外部 AI 工具中使用提示词生成 JSON，再粘贴回本页。
- 点击检查格式后使用 Zod 校验版本、类型字段、填空标记、选项数量和正确答案下标。
- 校验成功显示总条数及三种类型的数量。
- 选择目标知识库并确认导入；导入后返回知识库详情。

## 8. 开始背诵 `/study/setup`

用于生成本轮背诵队列。

- 若检测到上次未完成的快照，先弹窗选择“开始新一轮”或“继续背诵”。
- 选择方式提供单个知识库和混合多个知识库；分类树支持按分类全选/取消和展开/收起。
- 内容筛选支持知识库和内容形式（全部、回忆、遮挡、选择题）。
- 复习范围：
  - 今日应复习：`nextReviewAt <= 当前时间`。
  - 全部：当前筛选范围全部内容。
  - 今日新加入：当天创建的内容。
  - 手动选择：弹窗搜索并逐条选择。
  - 错题本：已收藏内容。
- 页面显示筛选后的条目数量，未选知识库或无匹配内容时禁用开始按钮。
- 开始后将条目 id 通过路由 state 传给 `/study`。

## 9. 背诵中 `/study`

这是实际执行复习的页面。

- 顶部显示本轮完成数/唯一条目总数、进度条、退出/结束本轮操作。
- “上一个”可撤销最近一次已完成评价并恢复原内容和复习记录。
- “收藏”切换当前内容的错题本收藏状态。
- 当前卡片显示类型、图片（如有）、题面和复习次数统计。
- 回忆卡点击卡片显示答案；遮挡卡显示所有隐藏块；选择题点击选项后立即显示对错和正确答案。
- 答案显示后可查看解释和笔记（按笔记展示配置控制）。
- 评价按钮为“忘记、模糊、认识”。
- “忘记/模糊”会记录尝试并把条目放回队列队尾进行强化；“认识”完成该条目并写入 `reviewLogs`。
- 主动结束或页面隐藏会把队列、会话状态、已完成记录和当前显示状态写入 `localStorage`，供下次恢复。
- 队列完成后自动进入 `/study/complete`。

## 10. 本轮完成 `/study/complete`

- 显示本轮完成或提前结束状态。
- 显示认识、模糊、忘记和强化复习次数。
- “继续背诵”返回 `/study/setup`。
- “今日打卡”将当天复习记录汇总写入 `dailyCheckins`；完成后按钮变为已打卡。

## 11. 记录 `/records`

记录页可用顶部下拉框按全部、分类或知识库筛选。

### 概览标签

- 30 天学习热力图：按每天复习记录数量显示强度，点击日期切换到日历。
- 最近 14 天掌握情况：将认识、模糊、忘记按天堆叠展示。
- 记忆保持：显示筛选范围内内容的预计保持度曲线。
- 未来 7 天复习压力：按 `nextReviewAt` 日期统计待复习量。
- 最近 7 天新增：按日期和知识库显示新增条数，点击日期进入日历明细。

### 日历标签

- 提供最近 30 天日期条，可切换查看某一天。
- 显示当天复习条数、新增条数和强化次数。
- 当天新增按知识库汇总。
- 复习记录显示知识库、评价结果、尝试次数和强化次数。

## 12. 错题本 `/mistakes`

- 展示所有 `favorite=true` 的内容，并按知识库分组。
- 每条显示卡片类型、没背会次数和内容摘要。
- 支持编辑，进入 `/add/manual?edit=:itemId`。
- 支持移除收藏，移除后不再出现在错题本和“错题本”复习范围中。

## 13. 设置 `/settings`

### 数据

- 导出 TXT：弹出文本预览，可复制、打开或下载。
- 导出 V2 备份：下载包含分类、知识库、内容、复习记录和打卡的 JSON。
- 导入备份：选择 JSON 文件，兼容 V1；校验通过后确认覆盖当前全部数据库内容。

### 背诵显示

- 设置笔记在背诵页“出答案后展示”或“题目下常驻展示”。该偏好写入 `localStorage`。

### 关于与数据清理

- 显示应用名、Web 版本和本地存储说明。
- “清空全部数据”会清空分类、知识库、内容、复习记录和打卡记录，操作前有确认弹窗。

## 14. 公共交互与路由说明

- 底部导航只负责四个一级页面；添加、背诵、详情等页面通过返回按钮回退。
- 详情、添加和背诵设置大量使用查询参数预选知识库，实际数据通过 IndexedDB 读取。
- 无效知识库 id 会显示“知识库不存在”；无内容或无匹配筛选时显示空状态。
- 页面操作完成后通常调用顶层 `refresh` 重新读取数据库；错题本取消收藏目前直接刷新当前窗口。

## 15. 旧版页面代码

`src/App.tsx` 还保留 `Home`、`Libraries`、`LibraryDetail`、`AddPage`、`Setup`、`Study`、`Records` 等旧版组件，以及 `LegacyApp` 路由分发。它们不是当前 `App` 使用的页面，但会增加维护和检索成本。后续升级前建议决定：删除旧版、拆分文件，或明确保留为兼容实现。
