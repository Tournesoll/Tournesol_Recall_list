# 项目初始情况

## 1. 项目概览

- 项目名称：Recall Lite（考研简易背诵）。
- 用途：面向个人考研复习的本地优先背诵工具，将内容放入知识库后，按复习范围进行间隔复习。
- 当前形态：一个 Vite Web 应用，以及一个加载 Web 构建产物的 Android 原生 WebView 壳。
- 数据位置：Web 端主要使用浏览器 IndexedDB；少量界面偏好和背诵中断快照使用 `localStorage`。项目没有账号、后端、云数据库或在线同步。
- AI 定位：AI 在应用外部运行。应用只负责生成固定提示词、接收用户粘贴的 JSON、校验并导入，不保存 API Key，也不直接调用 AI。

## 2. 当前功能

### 知识库与分类

- 创建、重命名、删除知识库。
- 创建顶级分类和子分类，支持多级分类树。
- 将知识库创建在指定分类下，或在分类之间移动；删除分类时其知识库移动到“未分类”。
- 删除知识库时同时删除该库下的背诵内容和复习记录。
- 知识库详情显示总条数、待复习数、预计掌握度、最近复习和全部内容。

### 背诵内容

支持三种内容类型：

1. `recall` 回忆卡：题面/问题与答案，点击后显示答案。
2. `cloze` 遮挡卡：使用 `{{答案}}` 标记一个或多个遮挡内容，点击后揭晓。
3. `choice` 选择题：2～6 个选项，选择后立即显示对错及正确答案。

手动添加和编辑支持：

- 选择知识库和内容类型。
- 可选一张图片，限制 2 MB，读取为 Data URL 保存。
- 可选笔记，并配置笔记“常驻”或“出答案后展示”。
- 可选题目解析，统一使用“题目解析”语义，不区分学科或题型；旧 `explanationType` 仅作兼容字段。
- 编辑已有内容、删除内容。

### 内容导入与导出

- 格式粘贴导入：粘贴标准 JSON，先校验再选择知识库导入。
- AI 整理导入：选择允许的卡片类型和是否生成题目解析，复制动态提示词到外部 AI；将 AI 返回的 JSON 粘贴回应用，使用 Zod 校验后导入。
- 导入内容统一生成 `batchId`，新内容立即进入待复习状态。
- 知识库或设置页可将内容导出为 TXT，支持预览、复制、浏览器打开和下载；知识库详情还支持系统分享（不支持时回退为下载）。

### 背诵流程

- 选择一个或多个知识库，也可按分类批量选择。
- 选择知识库、内容形式和复习范围：今日应复习、全部、今日新加入、手动选择、错题本收藏内容。
- 手动选择支持当前筛选范围内搜索、全选和逐条勾选。
- 复习时显示进度、当前卡片类型、复习次数和“没背会”次数。
- 回忆卡/遮挡卡点击卡片揭晓；选择题点击选项后立即判定，但复习等级仍由用户手动评价。
- 评价为“忘记 / 模糊 / 认识”后更新复习状态；忘记或模糊会把当前内容放回本轮队列稍后强化。
- 支持收藏/取消收藏、撤销上一个已完成评价。
- 页面隐藏或主动结束时保存未完成队列，下次进入“开始背诵”可选择继续或开始新一轮。
- 完成页显示认识、模糊、忘记和强化次数，可进行今日打卡。

### 记录、统计与错题本

- 首页显示今日已复习、待复习、打卡状态、最近 7 天复习量、记忆保持趋势、最近知识库和最近添加。
- 记录页支持“概览”和“日历”两个标签，并可按分类或知识库筛选。
- 概览包括 30 天学习热力图、最近 14 天掌握情况、记忆保持趋势、未来 7 天复习压力、最近 7 天新增内容。
- 日历查看指定日期的新增内容、复习记录、评价结果、尝试次数和强化次数。
- 错题本展示被收藏的内容，按知识库分组；可编辑或取消收藏。

### 设置与数据维护

- 导出 V2 JSON 备份，包含分类、知识库、内容、复习记录和打卡记录。
- 导入备份会校验文件并覆盖当前全部数据；兼容旧的 V1 备份格式。
- 配置背诵时笔记展示方式。
- 清空全部数据（不可撤销，依赖用户确认）。

## 3. 技术选型与依赖

### Web 前端

- React 18：组件化 UI 和页面状态管理。
- TypeScript 5.6：类型检查；`npm run build` 会执行 `tsc -b`。
- Vite 6：开发服务器和生产构建，配置 `base: "./"` 以适配本地 Android 资源。
- React Router DOM 7：使用 `HashRouter`，因此页面地址形如 `#/libraries`。
- 普通 CSS：`src/styles.css` 为基础样式，`src/v2.css` 为当前 V2 视觉层；没有大型 UI 组件库。
- Zod 4：AI 导入 JSON、V1/V2 备份 JSON 的结构校验。
- Dexie 4：IndexedDB 封装和事务操作。
- KaTeX 依赖已安装，但当前 `RichText` 实际是轻量 `$...$`/`$$...$$` 文本拆分并用 `code` 展示，尚未调用 KaTeX 渲染。

### 数据层

数据层集中在 `src/db.ts`，数据库名称为 `recall-lite`，当前 Dexie 版本迁移到第 5 版，包含：

- `libraryGroups`：分类树，字段包括 `id`、`parentId`、`name`、创建/更新时间。
- `libraries`：知识库，字段包括 `id`、`groupId`、`name`、创建/更新时间。
- `items`：背诵内容及复习状态。除三种卡片字段外，还保存图片、笔记、解释、收藏、复习次数、遗忘系数等。
- `reviewLogs`：每次完成一条内容后的复习结果、尝试次数和强化次数。
- `dailyCheckins`：每日打卡汇总。

ID 使用 `prefix_crypto.randomUUID()` 生成。删除、导入恢复、复习更新等关键操作使用 Dexie 事务。

### 复习算法

- 不使用 FSRS。当前固定间隔数组为：`1、2、4、7、15、30、60、120、240、365、730、1460` 天。
- `again`（忘记）将等级归零；`hard`（模糊）等级加 1；`good`（认识）等级加 2，均受最大等级限制。
- 新内容 `reviewLevel=0`、`nextReviewAt=createdAt`，因此立即属于待复习。
- 每条内容有 `retentionFactor`，用于首页/记录页的预计记忆保持曲线；它是估算指标，不是完整遗忘模型。
- 本轮内非“认识”的内容会重新排到队尾；最终完成时按本轮最差评价写入一条复习记录。

## 4. 代码结构与运行入口

当前代码没有按页面拆分目录，主要结构如下：

```text
src/
├── main.tsx       # React 根节点、HashRouter、全局样式入口
├── App.tsx        # 当前 V2 页面、组件、路由分发及旧版代码
├── db.ts          # Dexie 数据库、类型、复习算法、辅助函数
├── schemas.ts     # 导入和备份的 Zod schema
├── styles.css     # 基础 CSS
└── v2.css         # 当前 V2 视觉层补充样式
```

`App.tsx` 中的 `App` 组件负责一次性读取分类、知识库、内容、复习记录和打卡数据，并通过 `refresh` 在操作后重新读取。页面由 `location.pathname` 手动分发，没有单独的 route 配置文件。

当前实际启用的是以 `V2` 结尾的页面组件，例如 `HomeV2`、`LibrariesV2`、`StudyQueueV2`、`RecordsV2`。同文件前部仍保留一套旧版组件和 `LegacyApp`，但 `App` 当前不调用 `LegacyApp`；后续维护时应先确认是否清理或迁移。

## 5. Android 形态与构建

- Android 工程位于 `android/`，包名为 `com.recalllite.app`。
- 当前实现是原生 Java `WebView` 壳，不是当前规范中规划的 Capacitor 工程；`MainActivity` 将 `https://recall-lite.local/index.html` 映射到 APK 的 `assets` 目录。
- WebView 开启 JavaScript、DOM Storage、数据库、文件/内容访问；Debug 构建开启 WebView 调试。
- Android 配置：compile/target SDK 36，min SDK 24，Android Gradle Plugin 8.13.0，竖屏，状态栏和导航栏使用浅色主题。
- `android/sync-web.ps1` 会先运行 `npm run build`，再把 `dist/index.html` 和 `dist/assets` 复制到 `android/app/src/main/assets`。
- Android 构建：先在仓库根目录执行 `powershell -ExecutionPolicy Bypass -File .\android\sync-web.ps1`，再在 `android` 目录执行 `./gradlew.bat assembleDebug`。APK 默认位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 6. 当前已知边界与交接注意事项

- 没有后端、登录、云同步、账号体系或服务端 API。
- AI、OCR、PDF/Word 解析均不在应用内实现；AI 仅通过复制提示词和粘贴 JSON 完成。
- 图片只支持手动添加/编辑的一张图片，AI JSON 导入不含图片。
- 公式当前不会真正渲染为 KaTeX 数学排版；接手者若要完善，需要改造 `RichText`。
- `seedIfEmpty()` 提供示例数据初始化逻辑，但当前 `App` 入口未调用它；新设备首次打开时是否有示例数据应以实际数据库状态为准。
- `localStorage` 仍用于笔记展示偏好和背诵恢复快照；核心知识库和复习数据在 IndexedDB。
- 当前工作区存在未提交的代码和 Android 构建产物变更，接手时应先查看 `git status` 和差异，避免覆盖已有工作。
